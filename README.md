# Repair-Center-Rangsit-University-RSU-

# ระบบแจ้งซ่อมและบำรุงรักษา มหาวิทยาลัยรังสิต (RSU Smart Repair & Maintenance System)
**สำนักงานอาคารและสิ่งแวดล้อม (ตึก 13) - มหาวิทยาลัยรังสิต (CSC481)**

เว็บแอปพลิเคชันระบบแจ้งซ่อมและบำรุงรักษาอาคาร สถานที่ และครุภัณฑ์ มหาวิทยาลัยรังสิต พัฒนาด้วย **HTML5, CSS3, JavaScript, Bootstrap 5.3.3 และ Bootstrap Icons** อ้างอิงผังแม่บทอาคารและสถานที่จริงของ **มหาวิทยาลัยรังสิต (RSU Campus Map ตึก 1 - 16)** ควบคู่กับต้นแบบ GUI Wireframes 1-8 และผังฐานข้อมูล ERD (`erd fixed super final.png`) อย่างครบถ้วน สมบูรณ์ และรองรับ Responsive Web Design ทุกอุปกรณ์

📖 **อ่านเอกสารวิเคราะห์ระบบ, แผนผังฐานข้อมูล ERD อธิบายทุกฟิลด์, Workflow และแนวทางการตอบคำถามอาจารย์ ได้ที่:** [SYSTEM_DOCUMENTATION.md](SYSTEM_DOCUMENTATION.md)

## 🏫 ข้อมูลอาคารและสถานที่ มหาวิทยาลัยรังสิต ที่รองรับในระบบ

อ้างอิงจากแผนที่มหาวิทยาลัยรังสิต:
- **ตึก 1:** อาคารอาทิตย์ อุไรรัตน์ (ห้องประชุม 302, ห้องรับรอง)
- **ตึก 2:** อาคารประสิทธิรัตน์
- **ตึก 3:** อาคารอุไรรัตน์ (ห้องประชุม 201)
- **ตึก 4/1, 4/2:** อาคารวิทยาศาสตร์ (วิทยาลัยแพทยศาสตร์/พยาบาลศาสตร์)
- **ตึก 5:** อาคารวิษณุรัตน์ (คณะวิศวกรรมศาสตร์ / ห้องแล็บคอมพิวเตอร์)
- **ตึก 6:** โรงอาหารกลาง / อาคารกวนอิม
- **ตึก 7:** อาคารหอสมุด (โถงบริการ / หอสมุดกลาง)
- **ตึก 8:** อาคารคุณหญิงพัฒนา
- **ตึก 9:** อาคารประสิทธิ์พัฒนา
- **ตึก 10:** อาคารวิทยาลัยดนตรี / อาคารจอดรถ
- **ตึก 11:** อาคารรัตนคุณากร (สำนักทะเบียนและประมวลผล)
- **ตึก 12, 12/1:** อาคารรังสิตประยูรศักดิ์
- **ตึก 13:** อาคารสำนักงานอาคารและสิ่งแวดล้อม (ศูนย์บริการซ่อมบำรุง)
- **ตึก 14:** อาคารนันทนาการ (Fitness Center / สระว่ายน้ำ)
- **ตึก 15:** อาคาร Digital Multimedia Complex (วิทยาลัยนิเทศศาสตร์ / สตูดิโอตัดต่อ)
- **ตึก 16:** อาคารบริการ
- **ศาลาดนตรีสุริยเทพ / คอนเสิร์ตฮอลล์**

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
CSC481/
├── css/
│   └── style.css                 # สไตล์ชีตหลัก (ธีมมหาวิทยาลัยรังสิต ชมพู-น้ำเงิน RSU Gradient)
├── js/
│   ├── data.js                   # Mock Database อิง ERD และผังอาคาร ม.รังสิต (ตึก 1-16) + LocalStorage

├── login.html                    # หน้าเข้าสู่ระบบบุคลากร RSU (@rsu.ac.th) พร้อม Modal ลงทะเบียนใหม่ & รีเซ็ตรหัสผ่าน (GUI-1)
├── index.html                    # หน้าภาพรวมงานซ่อม / Dashboard ประจำเดือน (GUI-2)
├── new-request.html              # หน้าฟอร์มแจ้งซ่อมใหม่ (Auto-fill ตึก/ห้อง ม.รังสิต อัตโนมัติ) (GUI-3)
├── track-repair.html             # หน้าติดตามงานซ่อมและ Timeline 4 ขั้นตอน (GUI-4 & GUI-8 Mobile)
├── assigned-tasks.html           # หน้ารายการงานของช่างเทคนิคประจำตึก (GUI-5)
├── assets.html                   # หน้าทะเบียนครุภัณฑ์ (กรองตามตึก 1-16 ใน ม.รังสิต) (GUI-6)
├── maintenance-plans.html        # หน้าแผนบำรุงรักษาเชิงป้องกัน (PM แอร์, ไฟฟ้า, อุปกรณ์แล็บ) (GUI-7)
├── SYSTEM_DOCUMENTATION.md       # เอกสารอธิบาย Flow, ฐานข้อมูล ERD ทุกฟิลด์, คู่มือลืมรหัสผ่าน, แนวทางตอบอาจารย์
├── vercel.json                   # การตั้งค่าสำหรับ Deploy บน Vercel (Clean URLs & Route Rewrites)
├── .gitignore                    # ไฟล์และโฟลเดอร์ที่ไม่นำขึ้น Git
├── erd fixed super final.png     # ผังโครงสร้างฐานข้อมูล ERD
├── gui-1.png ~ gui-8.png         # ภาพต้นแบบ UI / Wireframe
└── README.md                     # เอกสารแนะนำโปรเจกต์
```

## 🚀 วิธีการเปิดใช้งาน (How to Run)

เว็บเซิร์ฟเวอร์เปิดใช้งานอยู่บน **Port 3000** สามารถคลิกเข้าใช้งานได้ทันที:
👉 **http://localhost:3000/login.html** หรือ **http://localhost:3000/index.html**

*(หรือสามารถดับเบิลคลิกเปิดไฟล์ `login.html` บน Desktop โฟลเดอร์ `CSC481` ได้โดยตรง)*
