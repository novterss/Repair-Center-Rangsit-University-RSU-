## 🌟 ฟังก์ชันเด่น

1. **เข้าสู่ระบบและแบ่งสิทธิ์ตามบทบาท** – Auth Guard กันการเข้าหน้าอื่นโดยไม่ล็อกอิน, สมัครสมาชิกใหม่ได้ (เฉพาะเจ้าหน้าที่/ช่าง), รีเซ็ตรหัสผ่านโดยยืนยันด้วยเบอร์โทรที่ลงทะเบียนไว้
2. **แจ้งซ่อมพร้อม Auto-fill สถานที่** – เลือกครุภัณฑ์แล้วระบบกรอกอาคาร/ชั้น/ห้องให้, แนบรูปหน้างานได้, ออกเลขใบแจ้งซ่อม `RQ-ปปดดวว-ลำดับ` ตามวันที่จริง (เช่น `RQ-691105-001`)
3. **มอบหมายช่าง** – แอดมินเลือกช่างจาก Dashboard ได้ทันที
4. **Timeline 4 ขั้นตอน** – ส่งคำขอ → รับเรื่องและมอบหมายช่าง → กำลังดำเนินการ → ซ่อมเสร็จ อัปเดตอัตโนมัติทุกครั้งที่สถานะเปลี่ยน
5. **สถานะครุภัณฑ์อัตโนมัติ** – มีใบแจ้งซ่อมค้าง = *รอตรวจสอบ*, กำลังซ่อม = *อยู่ระหว่างซ่อม*, ซ่อมเสร็จหมด = *ใช้งานปกติ*
6. **แผนบำรุงรักษาเชิงป้องกัน** – สถานะคำนวณจากวันที่ปัจจุบัน (เกินกำหนด / ใกล้ครบกำหนดภายใน 7 วัน), กด "บันทึกการทำบำรุง" แล้วระบบเลื่อนกำหนดครั้งถัดไปตามรอบให้เอง
7. **ส่งออกข้อมูลเป็น CSV** – จากหน้า Dashboard, ทะเบียนครุภัณฑ์ และแผนบำรุงรักษา (เปิดใน Excel ภาษาไทยไม่เพี้ยน)
8. **รองรับมือถือ** – เมนูด้านล่างจอและ Sidebar แบบ Drawer

## 🚀 วิธีเปิดใช้งาน

**บนเครื่อง (Local)** – รัน Local Server ในโฟลเดอร์โปรเจกต์ แล้วเปิด `http://localhost:3000/`

```bash
python -m http.server 3000
```

**บน Vercel** – เชื่อม Repository [novterss/Repair-Center-Rangsit-University-RSU-](https://github.com/novterss/Repair-Center-Rangsit-University-RSU-) กับ Vercel (Framework: **Other**) แล้วกด Deploy ทุกครั้งที่ push ขึ้น `main` Vercel จะ deploy ใหม่ให้อัตโนมัติ

> ⚠️ ข้อมูลเก็บใน LocalStorage ของเบราว์เซอร์ ทุกบทบาทจึงต้องใช้ **เบราว์เซอร์เดียวกัน** ถึงจะเห็นข้อมูลชุดเดียวกัน (รายละเอียดใน [SYSTEM_DOCUMENTATION.md](SYSTEM_DOCUMENTATION.md#7-ข้อจำกัดและแนวทางพัฒนาต่อ))
