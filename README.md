## 🌟 ฟังก์ชันเด่นของระบบ (Key Features)

1. **Authentication & Role-Based Access Control:**
   - ระบบตรวจสอบการเข้าสู่ระบบ (Auth Guard) เพื่อป้องกันการเข้าถึงหน้า Dashboard โดยไม่ผ่านการพิสูจน์ตัวตน
   - สลับบทบาทผู้ใช้ได้ทันทีผ่านเมนูด้านบน (Role Switcher) เพื่อทดสอบมุมมองของ แอดมิน, ช่างเทคนิค และเจ้าหน้าที่
   - รองรับการลงทะเบียนบุคลากรใหม่ และระบบรีเซ็ตรหัสผ่านในตัว (Forgot Password Modal)
2. **Auto-Fill ข้อมูลสถานที่จริงใน ม.รังสิต:**
   - เมื่อเลือกครุภัณฑ์ในหน้าแจ้งซ่อม ระบบจะกรอกอาคารและห้องติดตั้งจริงใน ม.รังสิต (ตึก 1 ถึง 16) ให้โดยอัตโนมัติ
3. **ระบบติดตามสถานะแบบ Timeline 4 ขั้นตอน (GUI-4 & GUI-8):**
   - ส่งคำขอ -> รับเรื่องและมอบหมายช่าง -> กำลังดำเนินการ -> ซ่อมเสร็จและตรวจรับ
   - แสดงช่องทางการติดต่อช่างเทคนิคผู้ดูแลงาน พร้อมเวลาคาดการณ์แล้วเสร็จ (ETA)
4. **Task Management สำหรับช่างเทคนิค (GUI-5):**
   - ช่างสามารถรับงาน ปรับสถานะ บันทึกผลการแก้ไข และแนบรูปภาพหลังการซ่อม
5. **Asset Registry & Preventive Maintenance Plans (GUI-6 & GUI-7):**
   - ทะเบียนครุภัณฑ์แยกตามตึก 1 ถึง 16 ใน ม.รังสิต
   - แผนบำรุงรักษาเชิงป้องกันตามรอบระยะเวลา (ทุก 1 เดือน, 3 เดือน, 6 เดือน, 1 ปี)

## 🏫 ข้อมูลอาคารและสถานที่ มหาวิทยาลัยรังสิต (RSU Campus Map ตึก 1 - 16)

- **ตึก 1:** อาคารอาทิตย์ อุไรรัตน์ (ห้องประชุม 302, ห้องรับรอง)
- **ตึก 2:** อาคารประสิทธิรัตน์
- **ตึก 3:** อาคารอุไรรัตน์ (ห้องประชุม 201)
- **ตึก 4/1, 4/2:** อาคารวิทยาศาสตร์ (วิทยาลัยแพทยศาสตร์ / พยาบาลศาสตร์)
- **ตึก 5:** อาคารวิษณุรัตน์ (คณะวิศวกรรมศาสตร์ / ห้องแล็บคอมพิวเตอร์)
- **ตึก 6:** โรงอาหารกลาง / อาคารกวนอิม
- **ตึก 7:** อาคารหอสมุด (หอสมุดกลาง ม.รังสิต)
- **ตึก 8:** อาคารคุณหญิงพัฒนา
- **ตึก 9:** อาคารประสิทธิ์พัฒนา
- **ตึก 10:** อาคารวิทยาลัยดนตรี / อาคารจอดรถ
- **ตึก 11:** อาคารรัตนคุณากร (สำนักทะเบียนและประมวลผล)
- **ตึก 12, 12/1:** อาคารรังสิตประยูรศักดิ์
- **ตึก 13:** อาคารสำนักงานอาคารและสิ่งแวดล้อม (ศูนย์บริการแจ้งซ่อม)
- **ตึก 14:** อาคารนันทนาการ (Fitness Center / สระว่ายน้ำ)
- **ตึก 15:** อาคาร Digital Multimedia Complex (วิทยาลัยนิเทศศาสตร์ / สตูดิโอตัดต่อ)
- **ตึก 16:** อาคารบริการ

## 🚀 วิธีการทดสอบบนเครื่อง Local

1. สามารถคลิกเปิดไฟล์ `login.html` บนโฟลเดอร์เครื่องได้โดยตรง
2. หรือรันผ่าน Local Server:
   - URL สำหรับเข้าสู่ระบบ: **http://localhost:3000/login.html**
   - หรือเปิดหน้า **http://localhost:3000/** (ระบบจะส่งไปยังหน้า Login ให้อัตโนมัติด้วย Auth Guard)

## 🌐 การ Deploy บน Vercel

โปรเจกต์พร้อมสำหรับการ Deploy บน **Vercel** ทันที:
1. เข้าไปที่ [https://vercel.com](https://vercel.com)
2. เชื่อมต่อกับ GitHub Repository: `https://github.com/novterss/Repair-Center-Rangsit-University-RSU-.git`
3. กด **Deploy** ไฟล์ `vercel.json` จะจัดเส้นทาง URL ให้สะอาด สวยงาม และเปิดหน้า Login เป็นหน้าแรกให้โดยอัตโนมัติ
